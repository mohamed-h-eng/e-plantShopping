# Paradise Nursery Shopping Application (e-plantShopping)

This is a dynamic web application for an online plant shop called Paradise Nursery, developed as part of the 'e-plantShopping' project. Users can browse plants, view details, add plants to a shopping cart, and manage cart items.

## Features

- **Landing Page:** Welcoming message and "Get Started" button.
- **Product Listing:** Browse plants by categories (Air Purifying, Aromatic, Insect Repellent, etc.).
- **Shopping Cart:** Manage items, adjust quantities, and see total costs.
- **Redux State Management:** Efficiently handle cart operations using Redux Toolkit.
